
# ФЕН



## Аналіз та структура проєкту

* **`faculty` (Частина 1):** Модуль факультету. Містить інформацію про факультет, кафедри, викладачів та випускові спеціальності. Весь контент керується через панель адміністратора.
* **`exchange` (Частина 2):** Модуль програм академічного обміну. Реалізовано еволюцію бази даних через серію послідовних та повністю зворотних міграцій (`0001`–`0008`).

---

## Як запустити проєкт

### 1. Клонувати репозиторій та перейти в папку проєкту:
```bash
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ>
cd web_laba_faculty
```

### 2. Створити та активувати віртуальне середовище:
* **macOS / Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
* **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\activate
  ```

### 3. Встановити залежності:
```bash
pip install Django
```

### 4. Застосувати міграції баз даних:
```bash
python manage.py migrate
```

### 5. Створити суперкористувача (для доступу до адмінки):
```bash
python manage.py createsuperuser
```

### 6. Запустити локальний сервер:
```bash
python manage.py runserver
```
